# Day 03 – Core Java

## Topics Covered

### 1. Constructor Chaining

- Understood constructor chaining and its purpose in Java.
- Learned how to invoke one constructor from another using `this()`.
- Studied how a child-class constructor invokes a parent-class constructor using `super()`.
- Practiced constructor overloading and constructor execution order.
- Understood that `this()` and `super()` must be the first statement in a constructor when used.

### 2. Packages in Java

- Revised the concept and purpose of packages in Java.
- Practiced creating user-defined packages using the `package` keyword.
- Learned how to import classes from other packages using `import`.
- Understood how packages organize classes and interfaces and help avoid naming conflicts.
- Practiced accessing classes across packages.

### 3. Access Specifiers

- Studied the four access levels in Java:
  - `public`
  - `protected`
  - Default (package-private)
  - `private`
- Understood how access permissions work within the same class, same package, subclasses, and other packages.
- Practiced applying access specifiers to variables, methods, and constructors.
- Learned how access control supports encapsulation and data hiding.

### 4. Introduction to IDE

- Learned the purpose of an Integrated Development Environment (IDE) for Java development.
- Explored the basic features of a Java IDE, including:
  - Creating Java projects and packages
  - Creating classes and writing code
  - Code completion and syntax highlighting
  - Compiling and running Java programs
  - Debugging and identifying errors
- Practiced creating, executing, and debugging Java programs in an IDE.

### 5. Arrays in Java

- Learned how arrays store multiple values of the same declared element type.
- Understood array declaration, initialization, indexing, and traversal.
- Practiced accessing array elements using loops.
- Learned that Java arrays are objects and have a fixed length after creation.

#### a. Primitive Type Arrays

- Studied arrays that store primitive values such as `int`, `char`, `double`, and `boolean`.
- Practiced creating, initializing, and accessing primitive arrays.
- Learned how default values are assigned to array elements when an array is created.

#### b. Reference Type Arrays

- Studied arrays that store references to objects, including `String` objects and user-defined class objects.
- Practiced creating arrays of objects and accessing their members.
- Understood that reference-type array elements initially contain `null` when not explicitly initialized.
- Learned the difference between an array containing primitive values and an array containing object references.

## Practical Work

- Implemented examples of constructor chaining using `this()` and `super()`.
- Created and accessed classes across user-defined packages.
- Practiced access control using different access specifiers.
- Created and executed Java programs using an IDE.
- Implemented primitive and reference-type array examples.
- Practiced array traversal and element access using loops.

## Learning Outcomes

- Understood constructor chaining and constructor execution order.
- Learned how to organize Java programs using packages.
- Gained practical knowledge of access control in Java.
- Became familiar with the Java development workflow in an IDE.
- Learned to create and manipulate primitive and reference-type arrays.
