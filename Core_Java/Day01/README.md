# Day 01 – Core Java Fundamentals

## Topics Covered

### 1. Why Java?
- Understood the purpose of Java and its importance in software development.
- Learned key features of Java:
  - Platform independent
  - Object-oriented
  - Simple and secure
  - Robust and portable
  - Multithreaded
  - Automatic memory management
- Explored Java applications in web development, enterprise software, and desktop applications.

### 2. Java Development and Execution
- Understood the basic Java program development and execution process.
- Learned how to write, compile, and execute a Java program.
- Practiced compiling source code using `javac` and running bytecode using `java`.
- Understood the role of Java source files (`.java`) and bytecode files (`.class`).

**Execution flow:**

`Source Code (.java) → Compiler (javac) → Bytecode (.class) → JVM → Output`

### 3. JDK, JRE, and JVM
- **JDK (Java Development Kit):** Provides tools required to develop and compile Java programs.
- **JRE (Java Runtime Environment):** Provides the runtime components needed to run Java applications.
- **JVM (Java Virtual Machine):** Executes Java bytecode.

Learned how the JDK, JRE, and JVM work together during Java development and execution.

### 4. Access Specifiers
- Studied the four access levels in Java:
  - `public`
  - `protected`
  - Default (package-private)
  - `private`
- Understood how access control affects classes, methods, constructors, and variables.
- Practiced controlling access to class members.

### 5. Java Data Types
- Learned the difference between primitive and reference data types.
- Studied the eight primitive data types:
  - Integer types: `byte`, `short`, `int`, `long`
  - Floating-point types: `float`, `double`
  - Character type: `char`
  - Boolean type: `boolean`
- Practiced declaring variables, assigning values, and selecting appropriate data types.

### 6. Type Casting
- Understood the conversion of one data type into another.
- Studied two types of primitive type casting:
  - **Widening casting:** Converts a smaller compatible type into a larger type automatically.
  - **Narrowing casting:** Converts a larger type into a smaller type explicitly.
- Practiced type conversion between numeric data types and observed possible data loss during narrowing.

### 7. Operators in Java
- Studied different categories of Java operators:
  - Arithmetic operators
  - Relational operators
  - Logical operators
  - Assignment operators
  - Unary operators
  - Bitwise operators
  - Shift operators
  - Ternary operator
- Practiced using operators in expressions and conditional logic.
- Understood operator precedence and associativity.

## Practical Work
- Created and executed basic Java programs.
- Practiced compiling and running Java programs from the command line or IDE.
- Implemented examples related to data types, type casting, access specifiers, and operators.
- Reviewed the fundamentals of Java program execution.

## Learning Outcome
Built a foundation in Java programming by understanding its features, development and execution process, runtime architecture, access control, data types, type casting, and operators.
