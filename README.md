# CDAC Repository

This repository contains assignments and practice programs from the Centre for Development of Advanced Computing (CDAC).

CDAC is a premier R&D organization under the Government of India, known for its PG-DAC (Post Graduate Diploma in Advanced Computing) program that focuses on software development, problem-solving, and industry-ready skills.

## 📚 Topics Covered

* Core Java
* Advanced Java
* Data Structures
* SQL
* CPP
* Web Development

## 🎯 Purpose

* Maintain daily learning progress
* Practice programming concepts
* Prepare for placements and interviews

## 🚀 Projects

### 1. Book My Stay

* A full-stack hotel booking web application
* Built using Spring Boot (Backend) and React (Frontend)
* Features:

  * User authentication (JWT-based)
  * Hotel search and booking system
  * Role-based access control
